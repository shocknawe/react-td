Generated procedurally on canvas, exported as 12 transparent PNGs. No diffusion model was involved — this is drawn in code, which is what tasks T16 and T20 call for anyway. Tier is carried by ring count, so a tier-3 tower is legible from the battlefield without reading a label.

Each element is a distinct shape, not just a distinct hue: petals, hexagonal lattice, zigzag spokes, spiral. That keeps them tellable apart in greyscale, which is the same a11y rule the icon set follows (T9).
